# المعرض (Gallery)

هذا المجلد يُملأ بالسكربت `scripts/build_gallery.py`، وهو ينشئ:

- `images/`: نسخ مجهولة الاسم من الرسومات (g001.png، g002.jpg، ...)
- `manifest.json`: المعرّف، ومسار الصورة، والتسمية الأصلية من KIDO، ودرجة النموذج المخزنة (cached)
- `review.html`: صفحة مراجعة للفريق فقط. لا تُنشر ولا يعرضها التطبيق.

التطبيق لا يرسل أبداً التسمية الأصلية أو اسم الملف الأصلي إلى المتصفح قبل أن يثبّت الزائر إجابته.
